# 온티켓(OnTicket) 실습 프로젝트 — 시작 폴더

'**현업에서 사용하는 AI Driven Development**' 과정의 실습을 시작하는 폴더입니다.

## 시작하기

1. 이 압축 파일을 원하는 위치(바탕화면·문서 폴더 등)에 **풉니다.**
2. VS Code를 열고 **File → Open Folder(폴더 열기)** 에서 이 **`onticket`** 폴더를 선택해 엽니다.
3. 왼쪽 탐색기에 `data/` 폴더가 보이면 준비 완료입니다.
4. 이제 교재의 안내에 따라 진행하세요. 이후 만들어지는 모든 코드는 **이 폴더 안에서** AI가 생성해 갑니다.

## 폴더 구성

```
onticket/
├── data/            실습에 쓰는 입력 데이터 (회의록 · CSV · 로그)
│   ├── 킥오프_회의록.md
│   ├── events.csv / ticket_types.csv / users.csv / orders.csv / checkins.csv
│   └── logs/app_error.log
├── docs/
│   ├── templates/   문서 템플릿 (PRD-템플릿.md — PM 스킬이 채운다 · API-Spec-템플릿.md — 아키텍트 스킬이 채운다)
│   └── 가이드/      회사 가이드 문서 (브랜드가이드라인 · 코딩컨벤션 · 프로젝트구조 · 깃커밋컨벤션)
└── README.md        (이 파일)
```

## 참고

- `data/` 안의 데이터는 **전부 가상 데이터**입니다. 실습 외 용도로 사용하지 마세요.
- 실습을 진행하면 이 폴더 안에 화면·서버·설정 파일 등이 하나씩 만들어집니다.
