# (주)승승장구 신규 서비스 '온티켓' 킥오프 회의록 — 2026.9.7(월) 14:00, 본사 회의실

참석: 오대표, 운영팀 박팀장, 개발 리더(나)

---

오대표 왈. 인터파크에 내는 수수료가 아깝다. **우리 공연 티켓을 우리가 직접 파는 사이트를 만들기로 결정.**
서비스명은 '온티켓'으로 이미 정했다고 함(상표 검토 끝).

지난 분기 실적 얘기 나옴. 플랫폼 안 거치고 팔아 본 '골목 라이브 vol.7'은 구글폼+계좌이체로 받았는데
**입금자명이 달라서 대조하는 데 이틀** 걸렸다고. 현장에서는 명단 엑셀 찾느라 입장 줄이 30분 밀림.
운영팀 전원 야근. 박팀장: "이거 한 번만 더 하면 퇴사각입니다."

원하는 거:
- 우리 공연 티켓을 **우리 사이트에서 직접 판매**. 예쁘고 신뢰감 있게. (요즘 감성으로, 촌스럽지 않게)
- 고객이 폰으로 3분 안에 결제까지 끝났으면 좋겠다고 함
- 결제는 계좌이체 말고 카드로. 박팀장: "카드번호 우리가 들고 있으면 무서워요"
  → **토스페이먼츠** 쓰기로 함(오대표 왈 "계약은 토스로 진행 중"). 카드정보는 토스가 받고 우리는 **승인 결과만 확인.**
- 티켓 등급이 공연마다 다름 (VIP/R/S도 있고, 스탠딩/지정석만 있는 공연도 있고, 얼리버드도 함)
- **매진되면 자동으로 못 사게** — 골목 라이브 때 초과 판매로 환불해주느라 난리났었음
- 결제하면 문자나 뭐 그런 걸로 티켓이 갔으면 함 → QR로 입장 확인하고 싶다고 (수기 명단 그만)
- 환불도 사이트에서 되면 좋겠다 함 (공연 7일 전까지 전액, 이후 50%라는데 정책은 아직 확정 아님)
- 박팀장: 공연별로 **몇 장 팔렸는지, 얼마 들어왔는지** 보는 화면 필요. 엑셀 다운로드도.
- 오대표: 잘 되면 나중엔 다른 기획사들도 입점시켜서 수수료 받는 플랫폼으로 키우자 함 (와디즈처럼?)
- 좌석 지정(1층 A열 3번 같은 거)도 언젠가는… 근데 당장은 등급별 수량만으로 충분하다고 함
- 아 그리고 카카오톡 알림, 인스타 연동, 대기자 명단, 초대권(0원 티켓), 현장 결제도 얘기 나옴

일정: **다음 주말 '리버사이드 재즈' 티켓 오픈 전에** 1차 버전이 떠야 함. 그니까 실질적으로 3일.
예산: 서버비 최소로. (오대표 왈 "AWS 같은 건 비싸지 않아요?")
개발 인력: 나 혼자. (오대표 왈 "요즘 AI로 다 된다면서요?")
