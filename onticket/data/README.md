# 온티켓(OnTicket) 실습 데이터

이 과정 실습에 쓰이는 데이터입니다. **전부 가상 데이터**입니다 — 실명·실연락처·실제 공연과 무관합니다.
(개인정보 형태의 값은 실습을 위해 원형으로 들어 있습니다. 실습 외 용도로 쓰지 마세요.)

## 파일

| 파일 | 내용 |
|---|---|
| `킥오프_회의록.md` | 신규 서비스 킥오프 회의록 — 기획 실습의 입력 |
| `events.csv` | 행사 목록 |
| `ticket_types.csv` | 행사별 티켓 등급·가격·수량 |
| `users.csv` | 회원 |
| `orders.csv` | 주문 (상태·QR 포함) |
| `checkins.csv` | QR 입장 기록 |
| `logs/app_error.log` | 특정 행사 당일 게이트 로그 (운영·장애 실습용) |

## 데이터 관계

```
users (1) ──< orders (N) >── ticket_types (N:1) ── events (1)
                 └──< checkins (QR 입장)
```

각 파일은 교재의 해당 차시 실습에서 불러 씁니다. 자세한 진행 방법은 교재를 따르세요.
