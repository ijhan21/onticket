## 2. 화면 흐름

- 고객: S01 → S02 → (결제대행 결제창) → S03
  - 결제가 실패·취소되거나 서버가 승인하지 않으면: S02 → (결제대행 결제창) → S04 → S02
  - 다시 볼 때: 어느 고객 화면이든 → S05
- 운영: S06 → S07 → S08 (등록·수정 후 S07로 돌아온다)
  - 현장: S06 → S07 → S09 (S09에서 티켓을 계속 확인한다)
- 3분 경로: 우리 화면 3개(S01 → S02 → S03)와 결제대행 결제창 1개. 고객이 우리 화면에 넣는 값은 3개(등급, 수량, 이메일)이고, 수량이 1장이면 2개(등급, 이메일)다. 누르는 것은 공연 항목, 등급, 결제하기 3번. 결제창 안의 입력은 결제대행이 정한다.
